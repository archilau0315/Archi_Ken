## 一、填写规范

每个模块统一按五步法（见计划 2.1.2）产出条目，填写到对应列：

| 步骤 | 产出 | 落库位置 |
|---|---|---|
| A 界面穷举 | UI 元素清单 + 功能映射 | `UI 元素清单` 列（链接到截图归档目录） |
| B 数据流追踪 | 调用链与产物结构图 | `数据流/产物解剖` 列 |
| C 规则语义还原 | 行为规格条目（输入→判定→输出） | 表 2（规则模板条目表） |
| D 性能基线 | 耗时/内存/帧率数据 | `性能基线` 列（指向基线报告） |
| E 技术栈特征 | 静态观察结论 | `技术栈特征` 列 |

**行为规格条目格式**（表 2 每一行必须能回答）：

```
输入条件（构件类型 + 属性/分类 + 范围）
  → 判定规则（算子 + 阈值 + 容差）
  → 输出结果（通过/失败 + 结果对象结构 + 严重度）
  → 探针模型（验证该条目的模型文件路径）
  → 实测边界（在 Solibri 上实测到的临界值）
```
