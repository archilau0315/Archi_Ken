# ArchiKen 模块清单 V0.1

> 与《ArchiKen 逆向开发技术路线与分阶段开发计划》第 2.3 节的分层架构一一对应。
> 状态口径：**已建骨架** = 目录与最小可运行代码已就位；**待建** = 尚未开始。

---

## 一、分层与目录映射

| 层 | 目录 | 职责（只做这些） | 当前状态 |
|---|---|---|---|
| L4 UI 交互层 | `src/` | 渲染、交互、本地视图状态；重计算一律下沉；界面中英双语（`src/i18n/`，默认中文） | 已实现（v1：三栏工作台 + 3D 视图 + 服务客户端 + i18n） |
| L4 桥接 | `electron/` | 本地编排：窗口、内核进程守护、文件访问、IPC 白名单 | 已实现（v1：IPC 请求转发） |
| L3 业务逻辑层 | `server/` | 编排、事务、权限、任务状态机、报告与 BCF 组装 | 部分实现（v1：结果与报告服务 + 规则集管理） |
| L2 核心计算层 | `kernel/` | 纯计算：解析、几何、碰撞、规则求值、IDS、提取、报表渲染 | 部分实现（解析 / 几何 / 碰撞 / 规则 / 合规 / 融合 / IDS） |
| L1 数据层 | （规划 `data/`） | 存储与索引；不含业务判定逻辑 | 待建 |

## 三、约束

1. 单一模块只做一件事；文件 ≤ 500 行，> 800 行必须拆分。
2. L2 模块必须幂等：同一输入重复执行得到同一输出。
3. 跨层调用只允许单向：L4 → L3 → L2 → L1，禁止反向依赖。
